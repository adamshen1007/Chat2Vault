## Review, remediations, and residual risk

Task-level independent reviews accepted the core parser/matcher, adapter, gate/UI, combined renderer/controller, and native asynchronous bounded-read path after their targeted fixes. Two controller-gate R2 passes found (1) an unauthenticated public post-gate write alias and then (2) computed/aliased access bypasses in the static scanners. The alias was removed. The only direct M06 call is inside the M07 revalidated execution spine; negative source and built-artifact fixtures cover the reported bypasses. The narrow R2 recheck found no remaining material controller-gate finding and verified source, gate-class, and complete `main.js` SHA-256 pins; those pins were refreshed for the later remediated controller/bundle bytes. The M05 artifact comparator was extended with exactly the two M07 runtime-only modules; arbitrary additional runtime inputs still fail. A separate runtime R2 review found that the first two packets concealed a pre-scenario provider request; those packets were replaced, not retained as qualification.

The first whole-candidate R2 review then found four issues: (1) a displayed-note confirmation could silently use a newer valid selected-note revision; (2) artifact-only verification did not compare retained packets to current artifacts; (3) changed source content and alternative extraction were rendered as one warning; and (4) unrelated invalid-UTF-8 Markdown blocked the catalog. The implementation now binds the displayed selected-note digest to preview and reloads/requires reconfirmation on mismatch; distinguishes both same-source reasons; ignores unrelated undecodable Markdown while rejecting owned malformed notes; and pins/validates both retained packets against all six current production artifacts plus the runtime seam. Focused race, subtype, decode, and substituted-packet tests cover these changes. Both official host rows were rerun on the remediated build. The fresh independent R2 review of tree `3bdd4c572d4e508c142115f05a156e623f4d34c6` passed and closed all four findings.

Known limits: the native bounded reader retains a disclosed absolute-root ancestor swap-and-revert race outside its descriptor-relative leaf checks; M07 makes no claim of eliminating that prior platform-level limitation. Combined creation is not a multi-note transaction; earlier verified creates remain if a later create fails, with an explicit ledger. Exact duplicates from a different source do not add provenance to an existing note because M07 forbids modifying it. Host qualification applies to the exact built artifact hashes only.

No manual action was needed for either M07 runtime row. The legacy M05 aggregate required a foreground click on this host; both host rows and the complete aggregate passed on 2026-10-13. No further manual verification action is pending for this candidate. The local commit is authorized; push, PR, merge, deployment, and release require separate Product Owner authorization.
